    Routing rules for the pilot

    • Prepaid and low risk: no nudge, no message cost.
    • COD or first-time address: nudge 48 hours before delivery.
    • No reply: automated call 2 hours before the slot.
    • Still no reply: the hub calls before dispatch, and the order is not sent blind.
    • "I didn't order this": parcel held, seller alerted.

    Move 2. If a parcel is still refused, it goes to the local hub, not back to the seller. The hub matches it to a nearby buyer and ships it as a brand-new, properly invoiced order.

      • Non-perishable, not personalised
      • Value under the ₹750 cap (~2x average order value; high-value items excluded)
      • Tamper seal intact, photo logged at check-in
      • Size and colour match the listing
